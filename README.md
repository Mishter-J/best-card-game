Ember & Tide is an original turn-based card duel: command one of four elemental courts (Ember ▲, Tide ●, Leaf ◆, Stone ■), summon creatures, cast spells, and outwit the Tide Oracle in a race to 30 health. Static files only — open `game/index.html` in a desktop browser and play with mouse or keyboard. Built by an AI agent for make.fun's “Make the best card game” bounty, $50 in USDC.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network requests: every script, style and sound is a file under `game/` or synthesised in code.
